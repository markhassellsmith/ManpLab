# Image Metadata Guide

## Overview
ManpLab embeds comprehensive fractal metadata into every exported PNG and JPEG image. This metadata allows you to reproduce any fractal rendering exactly, share parameter settings with others, and preserve your exploration history.

## Understanding the Metadata Properties

### What is Metadata?
Metadata is information *about* the image stored *within* the image file itself. It travels with the file when you copy, share, or archive it.

### Core Metadata Categories

**Software Attribution**
- **Software**: The application name and version that generated the image (`ManpLab v1.0`)
- **Source**: The project's GitHub repository URL for reference and attribution
- **Creation Time**: When the fractal was rendered (UTC timestamp)
- **Comment**: A human-readable note identifying this as a ManpLab-generated fractal

**Fractal Identification**
- **FractalFamily**: The mathematical family (e.g., "Mandelbrot", "Julia", "Newton's Method")
- **FractalName**: The specific fractal visualization name as shown in the UI
- **FractalType**: The internal fractal type identifier
- **IterationMode**: Whether this is a standard or Julia set rendering

**Mathematical Parameters**
- **CenterX / CenterY**: The complex plane coordinates at the image center (high-precision decimal)
- **Zoom**: The magnification level (higher = more zoomed in)
- **MaxIterations**: Maximum iteration count used for escape-time calculation
- **JuliaCX / JuliaCY**: Julia set constant (c) parameter, if applicable

**Rendering Details**
- **ColorPalette**: The color scheme used (e.g., "Classic", "Fire", "Ocean")
- **Resolution**: Image dimensions in pixels (e.g., "1920x1080")
- **RenderTime**: How long the fractal took to compute, in seconds

**Complete JSON Blob**
- **ManpLabMetadata** (PNG) or **UserComment** (JPEG): A full JSON object containing *all* metadata fields, enabling programmatic reproduction of the exact render

## How to View Metadata

### Windows
1. Right-click the image → **Properties** → **Details** tab
2. Look for fields like "Software", "Date taken", "Comments"
3. Note: PNG text chunks are *not* visible in Explorer; use a dedicated metadata viewer like [ExifTool](https://exiftool.org/)

### macOS
1. Right-click the image → **Get Info**
2. Expand the "More Info" section
3. Use `exiftool` command-line tool for complete PNG text chunk access

### Linux
- Use `exiftool <filename>` to view all metadata
- PNG: `pngcheck -t <filename>` shows text chunks
- JPEG: `exiftool <filename>` shows EXIF fields

### Cross-Platform Tools
- [ExifTool](https://exiftool.org/) (command-line, comprehensive)
- [XnView](https://www.xnview.com/) (GUI, shows PNG text)
- [ImageMagick](https://imagemagick.org/) `identify -verbose <filename>`

## Technical Notes

### PNG vs JPEG Metadata
- **PNG** stores metadata as plain-text tEXt chunks, making them human-readable and parsable by third-party tools
- **JPEG** uses standardized EXIF tags, which are widely supported by image viewers and photo management software
- Both formats include the full JSON blob for complete programmatic access

### High-Precision Storage
All floating-point values (CenterX, CenterY, Zoom, JuliaC) are stored using "round-trip" formatting (`ToString("R")`), which guarantees the exact original value can be reconstructed when parsing. This is essential for deep-zoom fractals where precision matters.

### Future Enhancements
- XMP metadata sidecar files for extended attribution
- IPTC keywords for fractal family tagging
- SVG metadata for vector-based Hailstone diagrams

## Programmatic Access

### Reading PNG Text Chunks (C#)
```csharp
using Windows.Graphics.Imaging;
using Windows.Storage.Streams;
using System.Text.Json;

var decoder = await BitmapDecoder.CreateAsync(stream);
var props = await decoder.BitmapProperties.GetPropertiesAsync(new[] { "/tEXt/ManpLabMetadata" });
var jsonBlob = props["/tEXt/ManpLabMetadata"]?.ToString();
var metadata = JsonSerializer.Deserialize<FractalMetadata>(jsonBlob);
```

### Reading JPEG EXIF (C#)
```csharp
var props = await decoder.BitmapProperties.GetPropertiesAsync(new[] { "/app1/ifd/exif/{ushort=37510}" });
var userComment = props["/app1/ifd/exif/{ushort=37510}"]?.ToString();
var metadata = JsonSerializer.Deserialize<FractalMetadata>(userComment);
```

### Using ExifTool (Command Line)
```bash
# View all PNG text chunks
exiftool -G1 -a -s fractal.png

# Extract JSON metadata from PNG
exiftool -ManpLabMetadata fractal.png

# Extract JSON metadata from JPEG
exiftool -UserComment fractal.jpg

# Batch extract metadata to CSV
exiftool -csv -r *.png > metadata.csv
```
