## Key Recommendations

### CRITICAL Properties (Must Always Include):
1. **Software**: `"ManpLab v1.0.0"` (with version number)
2. **Source**: `"https://github.com/markhassellsmith/ManpLab"`
3. **Timestamp**: Creation date/time
4. **Full Metadata**: JSON blob with all parameters

### Optional Properties (User Choice):
- **Author**: User's name
- **Copyright**: User's copyright notice
- **Title**: User's descriptive title
- **Description**: User's detailed description

## Implementation Strategy

### For PNG Files (Recommended):
```
Layer 1: /tEXt/ManpLabMetadata (JSON with SourceCode field)
Layer 2: /tEXt/Software + /tEXt/Source (standard properties)
Layer 3: User attribution (Author, Copyright, Title, etc.)
```

### For JPEG Files:
```
Layer 1: /app1/ifd/exif/{ushort=37510} (UserComment with JSON)
Layer 2: /app1/ifd/{ushort=305} (Software)
         /app1/ifd/{ushort=270} (ImageDescription with GitHub URL)
Layer 3: User attribution in standard EXIF fields
```

## Benefits

1. **Proper Credit**: Every image exported from ManpLab credits the software and its source
2. **Discoverability**: Users viewing the image can find ManpLab on GitHub
3. **Reproducibility**: Source code link ensures users can verify/reproduce results
4. **Community Growth**: Attribution helps grow the user base organically
5. **Open Source Transparency**: License information is embedded in metadata
6. **User Freedom**: Users can add their own attribution without overwriting software attribution
