# ManpLab Keyboard Shortcuts

Complete reference for all keyboard shortcuts in ManpLab.

> **Note:** F1 in-app help dialog may not work consistently due to focus issues. Use this document for reference.

---

## 📋 Quick Reference

| Key | Action | Notes |
|-----|--------|-------|
| **F1** | Show Keyboard Shortcuts Help | You're here! |

---

## 🖼️ Panels & UI

| Key | Action | Notes |
|-----|--------|-------|
| **Ctrl+B** | Toggle Browser Panel | Show/hide fractal browser |
| **Ctrl+P** | Toggle Properties Panel | Show/hide parameter editor |

---

## 🎨 Rendering

| Key | Action | Notes |
|-----|--------|-------|
| **Ctrl+R** | Render | Render current view |
| **F5** | Render | Same as Ctrl+R |
| **Escape** | Cancel Render | (Not yet implemented) |
| **Ctrl+S** | Save Image | Save as PNG |

---

## 🔍 Navigation (Fractals only, not Hailstone sequences)

| Key | Action | Notes |
|-----|--------|-------|
| **Space** | Reset View | Return to default viewport |
| **Home** | Reset View | Same as Space |
| **Ctrl+Z** | Undo Navigation | Go back in history |
| **Ctrl+Y** | Redo Navigation | Go forward in history |

---

## 🔎 Zoom (Fractals only, not Hailstone sequences)

| Key | Action | Notes |
|-----|--------|-------|
| **+** / **=** | Zoom In | Increase magnification |
| **Numpad +** | Zoom In | Same as above |
| **-** / **_** | Zoom Out | Decrease magnification |
| **Numpad -** | Zoom Out | Same as above |

---

## ⬆️⬇️⬅️➡️ Arrow Key Panning (Fractals only, not Hailstone sequences)

| Key | Action | Normal Pan | Fast Pan (with Shift) |
|-----|--------|------------|----------------------|
| **↑** | Pan Up | 10% of view height | 25% of view height |
| **↓** | Pan Down | 10% of view height | 25% of view height |
| **←** | Pan Left | 10% of view width | 25% of view width |
| **→** | Pan Right | 10% of view width | 25% of view width |

*Hold **Shift** for faster panning.*

## ⚙️ Algorithm Settings

| Key | Action | Notes |
|-----|--------|-------|
| **Page Up** | Increase Max Iterations | +100 (Shift: +500) |
| **Page Down** | Decrease Max Iterations | -100 (Shift: -500) |
| **I** | Toggle Auto-scale Iterations | Adjust iterations based on zoom |

## 🖱️ Mouse & Touch

| Action | Description |
|--------|-------------|
| **Click** | Zoom in at point |
| **Right-Click** | Zoom out at point |
| **Drag** | Pan the view |
| **Mouse Wheel** | Zoom in/out |
| **Touch** | Full touch support for panning and zooming |

---

## 💡 Tips

1. **Context-Sensitive**: Some shortcuts work differently for Hailstone sequences vs. fractals
2. **Shift Modifier**: Hold Shift for faster panning and larger iteration adjustments
3. **Disabled in Text Input**: Keyboard shortcuts are disabled when typing in text boxes
4. **F1 Anytime**: Press F1 to show this help dialog

---

## 🚀 Fast Workflow

**Quick exploration:**
```
1. Select fractal (Ctrl+B to open browser)
2. Space to reset view
3. Click to zoom in
4. Arrow keys to pan
5. + / - to adjust zoom
6. Ctrl+S to save
```

**Deep investigation:**
```
1. F5 to render
2. Adjust iterations (Page Up/Down)
3. Toggle Julia mode (T)
4. Toggle auto-scale (I)
5. Show axes (A)
6. Navigate history (Ctrl+Z / Ctrl+Y)
```
